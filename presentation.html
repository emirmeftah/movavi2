Цель проекта

Что это такое?

Приложение для управления личными задачами. Пользователь может добавлять задачи, отмечать их выполненными, удалять и отслеживать прогресс через панель аналитики — всё в режиме реального времени, без перезагрузки страницы.

Технологии

Стек технологий

🐍

Python 3.10+

Основной язык бэкенда. Типизация, современный синтаксис.

⚡

FastAPI

Современный веб-фреймворк. Автоматическая документация (Swagger), валидация данных.

🗄️

SQLite + SQLAlchemy

SQLite — база в файле, не требует сервера. SQLAlchemy — ORM для работы с Python-объектами.

🌐

HTML / CSS / JS

Чистый фронтенд без фреймворков. Fetch API, async/await, DOM-манипуляции.

07 / 09
Функционал

Что умеет приложение

✏️

Добавление задач

Форма ввода внизу экрана. Задача появляется без перезагрузки страницы.

✅

Отметка выполнения

Кнопка ✓ на каждой карточке. Задача перечёркивается, кружок зеленеет.

🗑️

Удаление задач

Кнопка × убирает задачу из базы данных и со страницы мгновенно.

📊

Аналитика

Панель: всего / выполнено / осталось / прогресс в %. Обновляется автоматически.

🔐

Аутентификация

HTTP Basic Auth. Каждый пользователь видит только свои задачи.

💬

Стиль Telegram

Задачи отображаются как чат-пузыри. Синий акцент, светлый фон.

Запуск

Как запустить проект

1️⃣

Клонировать репозиторий

git clone github.com/
emirmeftah/movavi2
git checkout claude/registration-api-no-db-pM4UQ

2️⃣

Установить зависимости

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

3️⃣

Запустить

Терминал 1:
uvicorn main:app --port 8000

Терминал 2:
python -m http.server 5500

4️⃣

Открыть в браузере

Приложение:
localhost:5500

Swagger API:
localhost:8000/docs
